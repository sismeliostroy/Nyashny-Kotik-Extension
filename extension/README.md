# Extension source snapshot

This directory is the complete unpacked Manifest V3 extension distributed as
`1.1.0-fix8`: manifest, locale files, HTML, CSS and executable JavaScript
modules. The upstream TypeScript/React project used to produce the original
Noctis bundles was not delivered with the extension archive, so this permitted
derivative is published from the available JavaScript source snapshot rather
than pretending that unavailable TypeScript sources exist.

The release ZIP is produced from this directory. `manifest.key` is intentionally
retained in `manifest.json` to preserve extension ID
`fgogfmjjadljkpiejmlmhoaafepfnooo` and browser storage during updates.
